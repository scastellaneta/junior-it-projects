# junior-it-projects

Progetti personali in Python e Java creati per esercitarmi nella programmazione.

## Contenuti

1) **Generatore Password (Python)**  
   Script Python che genera password casuali di lunghezza scelta dall'utente.

2) **Gestione Scuola (Java)**  
   Programma Java che determina la fascia scolastica dell'utente in base all'età e ne calcola la media dei voti tramite un metodo modulare.

---

## 🛠️ Tecnologie Utilizzate

- **Python**: manipolazione stringhe e generazione casuale.
- **Java**: programmazione strutturata, gestione dell'input (`Scanner`) e suddivisione in metodi.
